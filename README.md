# Global Opportunities (Kredibble Monorepo)

A production-grade talent and opportunity platform comprising a real-time Express backend, a Next.js 16 administrator dashboard, and an Expo 57 React Native mobile application.

```
Global-Opportunities/
├── kredibble-backend/   # Node 22+ / Express / Mongoose / Socket.io / Redis (port 4000)
├── kredibble-admin/     # Next.js 16 App Router / React 19 / Tailwind CSS v4 (port 3000)
└── kredibble-app/       # Expo 57 / React Native 0.86 / NativeWind v4 / SecureStore
```

---

## Prerequisites

- **Node.js**: `v22.13.0` or higher (`.nvmrc` targets Node 22/24)
- **npm**: `v10.8.0` or higher
- **MongoDB**: `v7.0` or higher (local service or Docker)
- **Docker & Docker Compose** (optional, for containerised database setup)

---

## 1. Local Database Setup

You can run MongoDB locally or via Docker Compose.

### Using Docker Compose
From the repository root:
```bash
docker compose up -d db
```
This spins up MongoDB on `localhost:27017`.

---

## 2. Backend Setup (`kredibble-backend`)

### Environment Configuration
Create `kredibble-backend/.env` with local configuration:
```env
NODE_ENV=development
PORT=4000
DATABASE_URL=mongodb://localhost:27017/kredibble
CORS_ORIGIN=http://localhost:3000,http://localhost:8081,http://localhost:19006
JWT_SECRET=development-jwt-secret-minimum-32-characters-long-example
ADMIN_JWT_SECRET=development-admin-jwt-secret-different-from-user-key-example
```

*(In development, missing secrets generate secure ephemeral secrets automatically; in production, 32+ character secrets are strictly enforced).*

### Installation & Initialization
```bash
cd kredibble-backend
npm install

# Initialize database schema and required text/unique indexes
npm run db:init

# Provision your initial administrator account
npm run user:create-admin -- --email admin@kredibble.com --name "Platform Admin"
```
The admin CLI generates a cryptographically secure 24-character password and outputs it once in your terminal.

### Start the API Server
```bash
npm run dev
```
The API boots at `http://localhost:4000`. Primary endpoints are versioned under `http://localhost:4000/api/v1`.

### Run Backend Tests & Linting
```bash
npm run lint
npm test
```

## 3. Admin Web Dashboard (`kredibble-admin`)

### Environment Configuration
Create `kredibble-admin/.env.local`:
```env
NEXT_PUBLIC_API_URL=http://localhost:4000/api/v1
```
*(In production deployment, the admin uses a same-origin proxy `/api` pointing to `API_PROXY_TARGET`).*

### Installation & Execution
```bash
cd kredibble-admin
npm install
npm run dev
```
Open `http://localhost:3000` in your browser. Sign in using the credentials generated by `npm run user:create-admin`.

### Run Admin Checks & Builds
```bash
npm run lint
npm run typecheck
npm run build
```

## 4. Mobile Application (`kredibble-app`)

### Environment Configuration
Create `kredibble-app/.env`:
```env
EXPO_PUBLIC_API_URL=http://localhost:4000/api/v1
```
*Note: If testing on a physical mobile device via Expo Go, replace `localhost` with your workstation's LAN IP address (e.g. `http://192.168.1.50:4000/api/v1`).*

### Installation & Execution
```bash
cd kredibble-app
npm install
npm run start
```

Target controls from the Metro prompt:
- Press `a` to open Android Emulator.
- Press `w` to open in a web browser.
- Scan the QR code using Expo Go on iOS or Android.

### Run Mobile Checks
```bash
npm run lint
npm run typecheck
npm test
```
